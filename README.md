# Лабораторна робота №8. Модульне програмування, створення пакетів та системні бібліотеки

**Виконала:** СТУДЕНТКА ГРУПИ ЕІ-24-1 МУНТЯН М.О.  
**Варіант:** 20

## Мета роботи

Опанування практичних навичок модульного програмування мовою Python, створення власних пакетів, використання модулів `sys`, `os`, `pathlib`, `time` та реалізації консольних утиліт із параметрами командного рядка.

## Завдання 1. Створення пакета системних утиліт

**Пакет:** `fs_toolkit`

**Реалізовані модулі:**
- `scanner.py` — рекурсивне сканування файлової системи.
- `reporter.py` — формування табличних звітів.
- `__init__.py` — ініціалізація пакета та експорт функцій.
- `cli_main.py` — головний модуль обробки аргументів командного рядка.

## Завдання 2. Сканування модифікованих файлів

**Назва утиліти:** `daily_mod_scan`

**Параметри командного рядка:**
- `--path` — шлях до каталогу сканування.
- `--hours` — кількість годин для пошуку файлів (за замовчуванням 24).
- `--help` — виведення довідки.

**Реалізовані операції:**
- Рекурсивний обхід каталогу методом `Path.rglob()`.
- Отримання метаданих файлів через `Path.stat()`.
- Перевірка часу останньої модифікації (`st_mtime`).
- Відбір файлів, змінених за останні N годин.
- Визначення розміру файлів і прав доступу.
- Формування таблиці результатів за допомогою f-рядків.
- Підрахунок загального розміру знайдених файлів.
- Вимірювання часу виконання програми.

## Результати виконання

Сканування тестового каталогу `test_sandbox` за останні 24 години:

- Знайдено файлів: 4.
- Загальний розмір: 0,21 КБ (0,0002 МБ).
- Час виконання: 3,011 мс.

Програма успішно виявила файли `system.log`, `firmware.bin`, `config.json` та `nested_dir/app_dump.log`.

## Використані технології

- Python 3.10+
- Visual Studio Code
- Модулі `sys`, `os`, `pathlib`, `time`
- Власний пакет `fs_toolkit`
- F-strings
- Аргументи командного рядка `sys.argv`

## Запуск програми

`python cli_main.py --path ./test_sandbox --hours 24`

## Висновок

У ході лабораторної роботи було створено багатофайловий Python-проєкт із власним пакетом `fs_toolkit`. Реалізовано консольну утиліту для рекурсивного пошуку файлів, змінених протягом заданого проміжку часу.
